# Science Corner

Science courses with readings, activities, and links to trusted sources. The courses are Atoms and molecules and Evolution.

Live site: https://brianmb99.github.io/science-corner/

## Add a course

1. Create `courses/your-topic.js` and push one course object onto `window.SCIENCE_COURSES`.
2. Add `<script src="courses/your-topic.js"></script>` in `index.html` before `app.js`.

The home page lists courses by the optional numeric `order` (lowest first), then newest-first by `added` (`YYYY-MM-DD`).

GitHub Pages serves this repo from `main`. The site's base path is `/science-corner/`.
